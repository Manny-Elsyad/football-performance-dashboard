# Football Performance Dashboard

A polished sports analytics dashboard built with Python, Streamlit, Pandas, and Plotly to explore football player performance metrics.

## Features

- Interactive filtering by position, club, minutes played, and goals
- Player comparison views for selected athletes
- Visual charts for goals versus assists, top performers, and distribution insights
- Clean, recruiter-friendly presentation with documentation and sample data

## Project Structure

- `app.py` – main Streamlit application
- `data/players.csv` – sample football player dataset
- `tests/` – automated validation for the dashboard logic

## Getting Started

1. Create and activate a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   streamlit run app.py
   ```
